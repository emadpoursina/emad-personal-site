# Emad Poursina — personal site

A personal website for Emad Poursina, a backend and AI-integration engineer. It gives recruiters and hiring managers (and the AI tools they use to screen applications) a credible, verifiable overview: a home page, three case studies, a downloadable CV, a contact form, and a visitor Q&A assistant.

**Status:** planning. The product spec is in [PRD.md](PRD.md) (v1.3, approved). No application code yet.

**Planned stack:** Astro 5 with a Node 22 SSR adapter, SQLite, nodemailer for contact email, Docker Compose for hosting on the owner's own machine (VPS later).
